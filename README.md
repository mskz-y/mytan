# マイ英単語帳

単語ファイル（TSV/CSV）をアップロードして使う、ブラウザ完結型の英単語帳アプリです。
データはブラウザの IndexedDB に保存され、サーバーへは送信されません。

**公開URL: https://mskz-y.github.io/mytan/**

## 使い方

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果を確認
```

`dev` / `preview` は同一 LAN からもアクセスできるので、スマホから PC の IP アドレスで開けます。
`dist/` は任意の静的ホスティング（GitHub Pages など）に置けば動作します。

## ファイル形式

1 行 1 単語、タブ区切り（`.csv` はカンマ区切り）で以下の 5 列。

| セクション | 単語またはフレーズ | 種類 | 日本語の意味 | 読み(IPA・省略可) |
|---|---|---|---|---|
| Lesson 1 | apple | 名 | リンゴ;リンゴの木 | ˈæpəl |
| Lesson 1 | run | 動/名 | 走る / 経営する / 走ること | rʌn |
| Lesson 1 | happy | 形 | 幸せな,うれしい | ˈhæpi |
| Lesson 2 | look forward to | 動 | …を楽しみに待つ |  |
| Lesson 2 | quickly | 副 | 速く,すぐに | ˈkwɪkli |

サンプル（TSV、列の区切りはタブ）:

```tsv
Lesson 1	apple	名	リンゴ;リンゴの木	ˈæpəl
Lesson 1	run	動/名	走る / 経営する / 走ること	rʌn
Lesson 1	happy	形	幸せな,うれしい	ˈhæpi
Lesson 2	look forward to	動	…を楽しみに待つ
Lesson 2	quickly	副	速く,すぐに	ˈkwɪkli
```

読み(IPA)が無い行は 4 列目までで構いません（上の `look forward to` の行）。

ファイル名（拡張子除く）が単語帳名になります。同名ファイルは上書き確認後に置き換えます。

## 機能

- 単語帳 / 単語帳(日英) / 単語帳(英日)：20・50・全件表示、英語・意味の表示切替、隠した項目はタップで個別表示
- フラッシュカード(日英・英日)：最初から／ランダム、読み上げ ON/OFF、3 秒・5 秒・10 秒・手動めくり
- 打ち込み：意味を見て英単語を入力、1 文字ずつ照合（スペース・記号は省略可、大文字小文字は区別しない）
- ファイル単位・セクション単位・グループ単位（複数セクションを組み合わせ）で学習可能
